# Audio Workout Coach: v0.4

October 4, 2026. This version supersedes v0.3. It keeps v0.3's goals and changes how the system is delivered.

## Goal
Generate an exactly 45:00 workout audio file on demand that can be downloaded. Noah's AI agent (Instinct) must be able to produce one without help. V1 needs speech that is understandable and correctly timed. Polish comes later.

## Decisions changed from v0.3
| v0.3 | v0.4 | Why |
|---|---|---|
| Local computer and operator | GitHub Actions in a public repo | No physical computer. Free for public repos. |
| ElevenLabs cues generated by hand on the website | Piper TTS (`en_US-norman-medium`) inside the Action | Fully automatic and free. The voice data is public domain. ElevenLabs moves to phase 2. |
| Local command plus file transfer | Request by GitHub issue; result posted as a release, with the link commented on the issue | Instinct can open issues and read comments, but can't make API calls with a token. |
| Drive or other transfer route | GitHub Release asset link | Public link, downloads directly on the iPhone. |

## Unchanged from v0.3
- Fixed 45:00 file, one male voice, rotating workouts chosen by a seed so the same seed always gives the same workout, built from an approved block library.
- The timeline must total exactly 2,700 seconds. Durations stay within each block's allowed range. Plans that break the rules are rejected, never stretched to fit.
- Quiet, low-impact, bodyweight-only work. Low-volume mix where the voice comes first and music is ducked under speech.
- Cues have fixed timestamps and must finish inside their block. Boundaries never move.
- The cool-down is never cut. Interruptions extend the finish time. Pain means stop.
- Lyrics-free CC BY music, credited in every output.
- Release checks: exact master sample count, decoded file within 0.1 s of 45:00, no cue overlaps, no clipping, credits complete.
- Twilio check-ins stay separate.

## What remains for V1 to be usable
1. **Noah reviews the exercise library** (`library/blocks/`). It is a placeholder.
2. **Listen test on the iPhone speaker** at quiet-room volume: music level, voice clarity, pacing. Tuning settings: `BED_RMS_DB` and `DUCK_DB` (music level and how far it drops under speech), `PIPER_LENGTH_SCALE` (speaking speed).
3. **Device checks** from v0.3 section 6: airplane-mode playback, locked screen, interruption behaviour.
4. **Confirm the author of Instinct's issues.** If they're not opened as `noahschmuckler`, add that login to the `RENDER_REQUESTERS` variable.
